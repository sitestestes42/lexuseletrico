PATCH V7 - CHECKOUT / PEDIDOS NATIVO PARA VERCEL

O login já está funcionando. Este patch corrige apenas a criação do pedido.

1) No GitHub, substitua:
   api/orders/create.ts

2) Confirme no Vercel que existem:
   SUPABASE_URL
   SUPABASE_PUBLISHABLE_KEY
   SUPABASE_SECRET_KEY

3) Se o checkout responder que as tabelas ainda não existem, abra:
   Supabase -> SQL Editor -> New query
   e execute o conteúdo de:
   supabase/checkout.sql

4) Depois teste novamente /checkout.

O endpoint valida a sessão no Supabase Auth, recalcula o preço no servidor,
evita pedido duplicado por idempotência e grava users/orders/order_items via Data API.
A SUPABASE_SECRET_KEY fica somente no backend e nunca é enviada ao navegador.
